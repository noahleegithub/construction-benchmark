# Architectural Design Verification Checklist (2025)

English translation of the Korean 2025 design-verification checklist for
architecture, consolidated from the 2025-07-01 policy draft and the
2025-07-09 distribution release.

**135 checklist items · 453 checkpoints.**

The Korean source is authoritative. Items retain their original numbering.
An English CSV and a machine-readable JSON file sit beside this document.

The 2025-07-01 draft and the 2025-07-09 release contain the same 135 item texts.
The draft's 490 checkpoint fragments all appear in the release's 453 consolidated
checkpoints; the difference is line wrapping, not omitted content.

## Checklist

### 1. Consistency with prior plans such as the district unit plan

**Area:** Title block and general sheets · **Drawing:** Inter-building distance layout plan · **Grade:** B · **Verification stage:** Initial review · **Classification:** Code violation / Code/guideline · **Deduction:** 0.2

**Checkpoints**

- [ ] Confirm consistency between the environmental impact assessment and the district unit plan
- [ ] Confirm the building limit line, maximum number of floors, floor height restriction, etc.
- [ ] Confirm parking count, buffer green space, agreement of the perpendicular layout, low-rise placement zones, etc.

**Additional comment.** For site entrances and similar plan elements, coordinate with the department responsible for higher-level plans such as the traffic impact assessment and incorporate the agreed adjustments where necessary.

### 2. Provision of dwelling units for the housing vulnerable in rental housing

**Area:** Title block and general sheets · **Drawing:** Architectural overview · **Grade:** C · **Verification stage:** Self-verification · **Classification:** Code violation / Code/guideline · **Deduction:** 0.2

**Checkpoints**

- [ ] Apply 8% or more in the Seoul metropolitan area and 5% or more in provincial areas

**Basis.** Enforcement Decree of the Housing-Vulnerable Support Act, Article 5

### 3. Appropriateness of gate post planning at the main site entrance

**Area:** Site planning · **Drawing:** Site layout plan · **Grade:** B · **Verification stage:** Initial review · **Classification:** Performance deficiency / Major defect · **Deduction:** 0.2

**Checkpoints**

- [ ] Provide sufficient separation between the crosswalk and the gate post to secure sight lines for pedestrian protection
- [ ] Secure a sidewalk width of 1.5m or more beside internal roads and install a road 7m or wider including the sidewalk
- [ ] Secure a gate post height of 4.5m or more where fire truck access is considered
- [ ] Install a pedestrian barrier fence between the gate post columns

**Additional comment.** Gate post height: 4m under the legal standard, 4.5m under the internal standard, and 5m per the National Fire Agency standard manual

**Other.** Improve the design, for example with a safety fence, so pedestrians cannot walk between the gate post columns

**Basis.** Site Quality Control Team-1961 ('15.6.29) · Standard Manual for Processing Consent for Building Permits, etc. ('23.12, National Fire Agency) · Design Guideline Article 14 (p. 48)

### 4. Appropriateness of vehicle access planning at the site entrance

**Area:** Site planning · **Drawing:** Site layout plan · **Grade:** B · **Verification stage:** Initial review · **Classification:** Performance deficiency / Major defect · **Deduction:** 0.2

**Checkpoints**

- [ ] Secure the driveway width in consideration of the 0.5m installation width of the barrier gate base pad
- [ ] Locate the access control system on the driver's side (left in the direction of travel)
- [ ] Install the visitor lane facing the guard booth so that it is visible from the booth
- [ ] Separate the access lanes for residents and visitors
- [ ] Where there are 3 or fewer entry/exit lanes, plan reversible entry and exit lanes

**Additional comment.** To prevent complaints about vehicle congestion, secure a vehicle queuing space from the barrier gate sized for 2 compact cars (approx. 10m)

**Other.** Where the traffic impact assessment requires a change to the entry/exit lane plan, coordinate with the relevant department and incorporate it

### 5. Appropriateness of planning for children's school-vehicle stops

**Area:** Site planning · **Drawing:** Site layout plan · **Grade:** B · **Verification stage:** Initial review · **Classification:** Performance deficiency / Major defect · **Deduction:** 0.2

**Checkpoints**

- [ ] Install a median at the main entrance or a roundabout so that school vehicles can stop
- [ ] Separate the circulation routes of general vehicles and school vehicles (planting bed recommended)
- [ ] Install pavement markings and signage to identify the school-vehicle stop
- [ ] Do not plan the stop where a crosswalk is installed
- [ ] Install safety facilities such as convex mirrors and vehicle-exit warning signs where necessary
- [ ] Where a kids station is installed, review sight lines to the stop

**Additional comment.** Install a low planting bed inside the roundabout to prevent accidents caused by driver blind spots when reversing

**Basis.** Rule on Housing Construction Standards, Article 6 · Regulation on Housing Construction Standards, Article 26

### 6. Installation of falling-object protection at entrances

**Area:** Site planning · **Drawing:** Site layout plan / Building floor plan · **Grade:** A · **Verification stage:** Main verification · **Classification:** General defect / General defect · **Deduction:** 0.05

### 14. Site planning in consideration of earth retaining and excavation

**Area:** Site planning · **Drawing:** Site layout plan · **Grade:** C · **Verification stage:** Self-verification · **Classification:** Performance deficiency / Major defect · **Deduction:** 0.2

- [ ] Install rakers toward the inside of the site

### 15. Appropriateness of the stormwater handling plan

- [ ] Review the suitability of stormwater trench locations (apartment buildings, auxiliary welfare facilities, etc.)

### 16. Confirmation of level markings and suitability at level differences

### 17. Appropriateness of neighborhood living facility planning

**Area:** Site planning · **Drawing:** Site layout plan / Auxiliary facility plan · **Grade:** B · **Verification stage:** Initial review · **Classification:** Performance deficiency / Major defect · **Deduction:** 0.2

**Checkpoints**

- [ ] Provide at least 1 accessible parking space
- [ ] Take measures such as planting to block noise and odors and for landscaping
- [ ] Install an access opening and inspection ladder below the 1st-floor restroom
- [ ] Provide a clear pit height of 1,800mm or more and a clear passage of 1,200mm or more

### 38. Verify adequacy of tile planning at dissimilar-material joints
