# Gateway area baseline (8k)

Early gateway run on the seven imported area tasks with a 8,000-token output
cap. Three models (`gpt-5.6-luna`, `gpt-5.6-sol`, `gpt-6.1-sol`) plus offline
oracle/stub controls.

This study is retained for provenance. It contains **two 8k truncations** and a
format failure, so its scores are not directly comparable to the 32k runs.
Primary 32k results are in `../area-tle-gpt6/` and `../area-tle-32k/`.

The door-threshold audit pack is under `audit/t-4f1/`; it documents why the
clear-width compliance task was retired.
